# 멍칼로리 계산기

강아지 프로필을 먼저 등록하고, 사료와 간식을 검색해 하루 총칼로리를 계산하는 작은 웹앱입니다.

## 기능

- 강아지 프로필 등록
- 제품명 검색
- 외부 식품 DB(Open Food Facts 기반) 다중 검색어 조회
- 사료/간식 분리 선택
- 기본 입력 위주 계산 + 고급 보정 입력
- 하루 간식 칼로리 + 하루 사료 칼로리 합산
- 강아지 체중/활동량 기준 권장 칼로리 비교
- 하루 급여 기록 저장 및 최근 기록 조회
- 검색 결과가 불완전할 때 고급 보정으로 수동 입력 가능

## 실행

기존 가상환경이 있다면 활성화한 뒤 아래처럼 실행합니다.

```bash
python3 dog_food_app/app.py
```

또는 준비해둔 실행 스크립트를 써도 됩니다.

```bash
zsh dog_food_app/run_app.sh
```

브라우저에서 아래 주소를 열면 됩니다.

```text
http://127.0.0.1:8020
```

같은 와이파이에 있는 휴대폰에서 보려면 맥북의 로컬 IP로 접속하세요.

예시:

```text
http://192.168.0.15:8020
```

맥북 IP 확인:

```bash
ipconfig getifaddr en0
```

와이파이가 아닌 다른 인터페이스를 쓰면 `en1`일 수도 있습니다.

## 셀룰러에서 보기

Cloudflare Tunnel을 쓰면 셀룰러에서도 접속할 수 있습니다.

1. 앱 서버 실행

```bash
zsh dog_food_app/run_app.sh
```

2. 새 터널 실행

```bash
zsh dog_food_app/run_tunnel.sh
```

3. 터미널에 표시되는 `https://...trycloudflare.com` 주소 접속

주의:

- Quick Tunnel 주소는 매번 바뀔 수 있습니다.
- 맥북이 잠들거나 서버/터널 프로세스가 종료되면 접속이 끊깁니다.

포트를 바꾸고 싶다면 환경변수를 사용하세요.

```bash
DOG_FOOD_APP_PORT=9000 python3 dog_food_app/app.py
```

## 계산 방식

- 1알 칼로리 = 간식 총칼로리 / 전체 알 수
- 하루 간식 칼로리 = 1알 칼로리 × 오늘 먹인 개수
- 하루 사료 칼로리 = 사료 급여량(g) × 사료 100g당 칼로리 / 100
- 하루 총칼로리 = 하루 간식 칼로리 + 하루 사료 칼로리
- 휴식 에너지(RER) = 70 × 체중(kg)^0.75
- 권장 하루 칼로리 = RER × 활동계수

## 참고

- 검색은 원본 검색어 외에 반려견 관련 보조 검색어도 함께 조회하도록 넓혀두었습니다.
- Open Food Facts는 공식 문서 기준 현재 가장 큰 오픈 식품 DB 중 하나이고, 2024년 기준 pet food 쪽 데이터도 같은 제품 DB로 통합 운영되고 있습니다.
- 저장된 기록은 `dog_food_app/data/daily_logs.json`에 누적됩니다.
- 실제 급여 기준은 수의사 권장량과 제품 포장 정보를 함께 확인하는 것이 안전합니다.
